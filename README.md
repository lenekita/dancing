# PHALANX — IRREAL LAB

Site statique du film PHALANX (anciennement UNISON), prêt pour GitHub Pages.
En ligne : https://lenekita.github.io/dancing/

## Contenu

- `index.html` : la page complète (styles et scripts inclus)
- `assets/poster.jpg` : affiche 1280 × 720
- `assets/phalanx.mp4` : le film, 1280 × 720, environ 7,3 Mo

## Mise à jour du dépôt `dancing`

1. Remplacer `index.html` et `README.md` à la racine.
2. Ajouter `assets/phalanx.mp4` et supprimer l'ancien `assets/unison.mp4`.
3. Le fichier `assets/xk.txt` est vide et peut être supprimé.
4. Commit puis push sur `main` : GitHub Pages republie automatiquement.

## Première publication (nouveau dépôt)

1. Créer un dépôt public et importer `index.html` et le dossier `assets` à la racine.
2. Dans **Settings → Pages**, choisir **Deploy from a branch**.
3. Sélectionner **main** puis **/(root)** et enregistrer.

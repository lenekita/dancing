# UNISON — IRREAL LAB

Site statique prêt pour GitHub Pages.

## Publication

1. Créer un dépôt public GitHub, par exemple `unison-film`.
2. Importer `index.html` et le dossier `assets` à la racine.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**.
4. Sélectionner **main** puis **/(root)** et enregistrer.

La vidéo web conserve le format 1280 × 720 et pèse environ 7,3 Mo.
